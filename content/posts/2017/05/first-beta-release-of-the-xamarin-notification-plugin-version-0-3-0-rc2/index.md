---
title: "First Beta Release of the Xamarin Notification Plugin (Version 0.3.0-RC2)"
date: 2017-05-24
---

The first beta version of the Xamarin Notification Plugin has been [released](https://github.com/saturdaymp/XPlugins.Notifications/releases/tag/0.3.0-RC2).  This plugin allows you to send local notifications easily using Xamarin.  You can find the release on [NuGet](https://www.nuget.org/packages/SaturdayMP.XPlugin.Notifications?NormalizedVersion=0.3.0-rc0002) under "[SaturdayMP.XPlugin.Notifications](https://www.nuget.org/packages/SaturdayMP.XPlugin.Notifications)".

More details and documentation can be found on the [GitHub page](https://github.com/saturdaymp/XPlugins.Notifications).  You can provide feedback to us (bugs, features, etc) by entering a issue [here](https://github.com/saturdaymp/XPlugins.Notifications/issues).  Finally if you want the bleeding edge check out the [MyGet feed](https://www.myget.org/feed/saturdaymp/package/nuget/SaturdayMP.XPlugin.Notifications).
