In episode 84 of the SaturdayMP show, [Omar Ashour](https://www.linkedin.com/feed/update/urn:li:activity:7427396657673220097/#) and myself ([Chris C.](https://www.linkedin.com/feed/update/urn:li:activity:7427396657673220097/#)) create a very basic main screen using Fyne to input the text to post and a button to create the LinkedIn post. That said, the GUI doesn't do anything yet, except look nice-ish. Lots of reading the Fyne documentation and experimenting with Fyne.
