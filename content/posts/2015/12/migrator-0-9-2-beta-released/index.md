[![smallgoose](images/smallgoose.webp)](https://bitbucket.org/saturdaymp/migrator/overview)Version **0.9.2 (beta)** of [Migrator](https://bitbucket.org/saturdaymp/migrator/overview) is now available for [download](https://bitbucket.org/saturdaymp/migrator/downloads).

This release fixed a show stopping issue where Migrator would not work on some older versions of SQL.  It also fixed an issue with the order dependencies are scripted. See the [release notes](https://bitbucket.org/saturdaymp/migrator/wiki/Migrator%200.9.2%20Release%20Notes%20\(December%206th,%202015\)) for all the details.

Documentation about using and installing Migrator can be found at on the [wiki](https://bitbucket.org/saturdaymp/migrator/wiki/Home).  If you find a bug with this release please let us know by entering a new [issue](https://bitbucket.org/saturdaymp/migrator/issues?status=new&status=open).

Happy Holidays!
