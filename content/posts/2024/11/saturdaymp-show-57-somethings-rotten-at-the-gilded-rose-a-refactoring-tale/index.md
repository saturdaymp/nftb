In this episode I tackle the famous [Gilded Rose](https://github.com/emilybache/GildedRose-Refactoring-Kata) refactoring kata as practice for my upcoming Edmonton .NET User Group ([EDMUG](https://edmug.net)) presentation. One of the great things about the Gilded Rose kata is the different ways to "solve" it. What would have done different then me?

Slides and source code for the presentation can be found [here](https://github.com/saturdaymp-examples/a-refactoring-tale).
