I'm happy to announce that [XPlugins.iOS.BEMCheckBox](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox) v2.0.0 has been released! This a wrapper for the [BEMCheckBox](https://github.com/saturdaymp/BEMCheckBox) which lets you create highly customizable, animated checkboxes for iOS. You can find the v2.0.0 NuGet package [here](https://www.nuget.org/packages/SaturdayMP.XPlugins.iOS.BEMCheckBox/2.0.0#readme-body-tab).

[![BEMCheckBox Example Gif](images/BEMCheckBox.gif)](https://nftb.saturdaymp.com/wp-content/uploads/2023/08/BEMCheckBox.gif)

This release includes all the fixes to the underlying BEMCheckBox from [v1.4.1](https://github.com/saturdaymp/BEMCheckBox/releases/tag/1.4.1) to [v2.0.0](https://github.com/saturdaymp/BEMCheckBox/releases/tag/v2.0.0). This includes the following breaking changes:

- Minimum iOS version was increased from 8.4 to 12.

- Events renamed:
    
    - `DidTapCheckBox` renamed to `DidTap`
    
    - `AnimationDidStopForCheckBox` to `AnimationDidStopFor`

Give it a try and let me know if you spot any errors or improvements by opening a [issue](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/issues) or [pull request](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/pulls). Please also send me any questions you have via a [issue](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/issues).

Thank you [Boris-Em](https://github.com/Boris-Em) for creating [BEMCheckBox](https://github.com/saturdaymp/BEMCheckBox). Myself, and likely lots of other people, really appreciate it.
