[![BEMCheckBox Example Gif](images/BEMCheckBox.gif)](https://nftb.saturdaymp.com/wp-content/uploads/2023/08/BEMCheckBox.gif)

I'm happy to announce that [v3.](https://www.nuget.org/packages/SaturdayMP.XPlugins.iOS.BEMCheckBox/3.0.1)[0](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/releases/tag/v3.0.1)[.1](https://www.nuget.org/packages/SaturdayMP.XPlugins.iOS.BEMCheckBox/3.0.1) of the [XPlugins.iOS.BEMCheckBox](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox) has been released! This release updates XPlugins.iOS.BEMCheckBox so it can be used in .NET 6.0 and higher projects (e.g. net6.0-ios12). You can find the latest release on NuGet [here](https://www.nuget.org/packages/SaturdayMP.XPlugins.iOS.BEMCheckBox/3.0.1).

You can ignore the [v3.0.0](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/releases/tag/v3.0.0) release. The NuGet package incorrectly listed the minimum iOS version as 16.1 (e.g. net6.0-ios16.1) instead of 12.0 (e.g. net6.0-ios12).

Let me know if you spot an issue or have an improvement by opening an [issue](https://github.com/saturdaymp/XPlugins.iOS.BEMCheckBox/issues).

Thank you [Boris-Em](https://github.com/Boris-Em) for creating [BEMCheckBox](https://github.com/saturdaymp/BEMCheckBox). Myself, and others, really appreciate it.
